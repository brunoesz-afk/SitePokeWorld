# PokeWorld

Página estática de download do PokeWorld para Android.

## Publicar o APK

Coloque o arquivo do jogo nesta pasta com o nome `PokeWorld.apk`, ao lado de `index.html`. A página verifica a presença do arquivo e libera o botão de download automaticamente.

## Testar localmente

Abra `index.html` em um navegador. Para testar a detecção do APK, sirva esta pasta por HTTP, por exemplo com a extensão Live Server do VS Code. O arquivo precisa estar presente para o botão ser ativado.

## Hospedar

Publique o conteúdo desta pasta em qualquer hospedagem de site estático. Envie `PokeWorld.apk` junto com os arquivos do site para que o download fique disponível.
